Confidentialité

Document à valider et compléter avant exploitation commerciale. Cette page décrit le fonctionnement technique de la version actuelle du site, sans présumer des traitements futurs d'AXEN.

Le formulaire de contact

Le formulaire fonctionne dans votre navigateur : les données saisies servent à préparer un email dans votre messagerie, si une adresse de destinataire est configurée. Aucune transmission automatique ni conservation dans une base de données AXEN n'est effectuée par le site. Si la destination n'est pas configurée, la demande peut être copiée sur votre appareil, mais elle n'est pas envoyée.

Statistiques et cookies

Cette version n'intègre aucun outil de mesure d'audience, traceur publicitaire ou cookie applicatif. L'hébergeur GitHub Pages peut traiter les informations techniques nécessaires à la fourniture du service, selon sa propre documentation.

Contacter le responsable de traitement

L'identité juridique et l'adresse de contact de l'éditeur doivent être ajoutées avant exploitation. Les modalités de traitement des emails reçus devront alors être documentées selon l'activité réelle.
